# 本地开发启动指南

## 前置要求

| 工具 | 版本要求 | 检查命令 |
|------|----------|----------|
| Python | 3.11+ | `python --version` |
| Node.js | 18+ | `node --version` |
| npm | 9+ | `npm --version` |

---

## 第一步：拿到 Railway Postgres 连接串

1. 打开 [railway.app](https://railway.app) 登录
2. **New Project** → **Add a Service** → **Database** → **PostgreSQL**
3. 点进 PostgreSQL 服务 → 顶部点 **Settings** 标签
4. 找到 **Networking** → 点 **Generate Domain**（生成公网访问地址）
5. 回到 **Variables** 标签 → 找 **`DATABASE_PUBLIC_URL`**，复制这个值

> 注意：`DATABASE_URL` 是内网地址（`.railway.internal`），本地不能用。  
> 要用 **`DATABASE_PUBLIC_URL`**，格式类似：  
> `postgresql://postgres:AbCdEfGh@roundhouse.proxy.rlwy.net:12345/railway`

## 第二步：配置后端环境变量

```bash
cd /Users/juliawang/Desktop/agewell/backend
```

编辑 `.env` 文件（已存在，只需替换占位符）：

```bash
# 用任意编辑器打开，或直接用 echo 写入：
cat > .env << 'EOF'
DATABASE_URL=postgresql://postgres:你的密码@你的host.railway.app:端口/railway
USE_MOCK=1
EOF
```

> `USE_MOCK=1` 表示 AI 响应用写死的 mock 数据，不需要 OpenAI/DeepSeek key，UI 流程一样能跑通。  
> 等你有 LLM key 后再加：`DEEPSEEK_API_KEY=sk-...`

## 第三步：创建 Python 虚拟环境并安装依赖

**方案 A：用 conda（推荐，你已有 miniconda）**

```bash
cd /Users/juliawang/Desktop/agewell/backend

# 创建独立环境（只需做一次）
conda create -n agewell python=3.11 -y

# 激活
conda activate agewell

# 安装依赖
pip install -r requirements.txt
```

**方案 B：用 venv（纯 Python 原生）**

```bash
cd /Users/juliawang/Desktop/agewell/backend

# 创建虚拟环境（只需做一次）
python -m venv .venv

# 激活
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

验证安装成功：

```bash
python -c "import psycopg; print('psycopg OK')"
python -c "import fastapi; print('fastapi OK')"
```

## 常见问题

### `ModuleNotFoundError: No module named 'psycopg'`
虚拟环境没激活，或依赖没装到当前环境。  
解决：`conda activate agewell` 后再 `pip install -r requirements.txt`。

### `connection refused` / `could not connect to server`
`.env` 里的 `DATABASE_URL` 填的是内网地址（`.railway.internal`）。  
解决：Railway → PostgreSQL → Variables → 复制 **`DATABASE_PUBLIC_URL`**（不是 `DATABASE_URL`）。

### 前端发请求报 `502` 或 `Network Error`
后端没起，或端口不是 8000。  
检查：`curl http://localhost:8000/healthz`

### AI 回复是假数据（mock 模式）
`.env` 里有 `USE_MOCK=1`，这是正常的。删掉这行，加上真实的 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY` 即可切换到真实 AI。
