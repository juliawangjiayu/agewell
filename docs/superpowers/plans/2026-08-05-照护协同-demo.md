# 照护协同 Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个网页版三人群聊 demo，展示照护判断引擎——女佣观察→分级/相关方/差异化输出，雇主指令→拆解/逐项确认，并支持"一键对比载入 skill vs 通用大模型裸跑"与语音输入输出。

**Architecture:** 单 agent 按发信人角色路由到两条流，共用一个 SQLite 家庭上下文库；判断层是两份 skill（结构化指令，护城河），由 orchestrator 注入具备语音能力的强模型；`skill_on` 开关控制载入 skill 还是中性翻译指令。前端 React（CodeBuddy 生成），后端 FastAPI。

**Tech Stack:** Python 3.11 / FastAPI / SQLite（stdlib）/ pytest / pydantic v2 / DeepSeek-V4（OpenAI 兼容接口；判断层文字推理）/ React（CodeBuddy）。语音见 Task 8 说明。

## Global Constraints

- **判断层是护城河**：两份 skill 的判断规则（分级/相关方/拆解）不外包，由懂照护/临床的人把关；本计划把 skill 编写与评测排在最前（Task 4/5）。
- **skill 用评测而非单测**：判断层非确定性，用 `backend/evals/` 的评测用例断言 `grade` 与 `notify`，人工核对文本质量；确定性代码（DB/orchestrator 解析/API/router）走标准 TDD + MockLLMClient。
- **对比模式的诚实性**：`skill_on=True/False` 必须调**同一个模型、同一条输入**，唯一变量是 system prompt（skill vs 中性指令）。
- **语音**：不用 Web Speech API；音频输入与语音合成都走强模型（见 spec 第九节）。
- **占位数据**：demo 展示文字用 spec 第五节的具体内容，`[方括号]` 为需人审替换项，代码里保留方括号原文。
- **提交纪律**：每个 Task 末尾提交一次；commit message 用中文 `type: 描述`。
- **模型先假设 DeepSeek-V4**：`RealLLMClient` 用 OpenAI 兼容 `chat.completions`，模型 id/endpoint/key 从环境变量读；换模型只改 env，不改代码。⚠️ 若 DeepSeek-V4 无原生语音，Task 8 的语音走另配语音模型或降级为可选（不影响判断层文字链路与评测）。

```python
import sqlite3

def get_conn(path: str = "agewell.db") -> sqlite3.Connection:
    conn = sqlite3.connect(path)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    return conn

def init_schema(conn: sqlite3.Connection) -> None:
    conn.executescript(
        """
        CREATE TABLE IF NOT EXISTS families (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            elder_json TEXT NOT NULL,
            medications_json TEXT NOT NULL,
            followups_json TEXT NOT NULL,
            household_json TEXT NOT NULL,
            helper_json TEXT NOT NULL
        );
        CREATE TABLE IF NOT EXISTS observations (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            family_id INTEGER NOT NULL REFERENCES families(id),
            date TEXT NOT NULL,
            raw_text TEXT NOT NULL,
            restored_text TEXT NOT NULL,
            grade TEXT NOT NULL,
            created_at INTEGER NOT NULL DEFAULT (strftime('%s','now'))
        );
        CREATE TABLE IF NOT EXISTS messages (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            family_id INTEGER NOT NULL REFERENCES families(id),
            role TEXT NOT NULL,
            content TEXT NOT NULL,
            created_at INTEGER NOT NULL DEFAULT (strftime('%s','now'))
        );
        """
    )
    conn.commit()
```

```python
import json
import sqlite3

class FamilyRepo:
    def __init__(self, conn: sqlite3.Connection):
        self.conn = conn

    def create_family(self, ctx: dict) -> int:
        cur = self.conn.execute(
            "INSERT INTO families (elder_json, medications_json, followups_json, "
            "household_json, helper_json) VALUES (?,?,?,?,?)",
            (json.dumps(ctx["elder"], ensure_ascii=False),
             json.dumps(ctx["medications"], ensure_ascii=False),
             json.dumps(ctx["followups"], ensure_ascii=False),
             json.dumps(ctx["household"], ensure_ascii=False),
             json.dumps(ctx["helper"], ensure_ascii=False)),
        )
        self.conn.commit()
        return cur.lastrowid

    def get_family(self, family_id: int) -> dict:
        row = self.conn.execute("SELECT * FROM families WHERE id=?", (family_id,)).fetchone()
        if row is None:
            raise KeyError(family_id)
        return {
            "id": family_id,
            "elder": json.loads(row["elder_json"]),
            "medications": json.loads(row["medications_json"]),
            "followups": json.loads(row["followups_json"]),
            "household": json.loads(row["household_json"]),
            "helper": json.loads(row["helper_json"]),
            "recent_observations": self.recent_observations(family_id),
        }

    def add_observation(self, family_id: int, date: str, raw_text: str,
                        restored_text: str, grade: str) -> None:
        self.conn.execute(
            "INSERT INTO observations (family_id, date, raw_text, restored_text, grade) "
            "VALUES (?,?,?,?,?)",
            (family_id, date, raw_text, restored_text, grade),
        )
        self.conn.commit()

    def recent_observations(self, family_id: int, limit: int = 10) -> list[dict]:
        rows = self.conn.execute(
            "SELECT date, raw_text, restored_text, grade FROM observations "
            "WHERE family_id=? ORDER BY id DESC LIMIT ?",
            (family_id, limit),
        ).fetchall()
        return [dict(r) for r in rows]

    def set_last_med_change(self, family_id: int, date: str) -> None:
        row = self.conn.execute("SELECT followups_json FROM families WHERE id=?",
                                (family_id,)).fetchone()
        followups = json.loads(row["followups_json"])
        followups["last_med_change_date"] = date
        self.conn.execute("UPDATE families SET followups_json=? WHERE id=?",
                          (json.dumps(followups, ensure_ascii=False), family_id))
        self.conn.commit()
```

```python
from abc import ABC, abstractmethod

class LLMClient(ABC):
    @abstractmethod
    def complete(self, system: str, user_text: str | None = None,
                 audio: bytes | None = None) -> str: ...
    @abstractmethod
    def speak(self, text: str) -> bytes: ...

class MockLLMClient(LLMClient):
    """按 system prompt 中出现的『特征子串』返回预设值。
    键取各 skill 文件里独有的标题短语（如『女佣端照护判断』/『翻译助手』），
    这样即便 skill 文件内容变化，只要标题稳定，测试就稳定。"""
    def __init__(self, responses: dict[str, str]):
        self.responses = responses
    def complete(self, system: str, user_text: str | None = None,
                 audio: bytes | None = None) -> str:
        for key, value in self.responses.items():
            if key != "_default" and key in system:
                return value
        return self.responses.get("_default", "")
    def speak(self, text: str) -> bytes:
        return ("AUDIO:" + text).encode()
```

```python
import json
from pathlib import Path
from app.llm import LLMClient

SKILL_DIR = Path(__file__).parent / "skills"
_SKILL_FILES = {"helper": "helper_skill.md", "employer": "employer_skill.md"}

def load_skill(role: str, skill_on: bool) -> str:
    fname = "neutral.md" if not skill_on else _SKILL_FILES[role]
    return (SKILL_DIR / fname).read_text(encoding="utf-8")

def build_user_content(ctx: dict, text: str) -> str:
    return ("【家庭上下文】\n" + json.dumps(ctx, ensure_ascii=False, indent=2) +
            "\n\n【本轮输入】\n" + text)

def parse(role: str, skill_on: bool, raw: str) -> dict:
    if not skill_on:
        return {"skill_on": False, "text": raw.strip()}
    try:
        data = json.loads(raw)
    except json.JSONDecodeError:
        return {"skill_on": True, "error": "unparseable", "raw": raw}
    data["skill_on"] = True
    return data

def handle(llm: LLMClient, ctx: dict, role: str, text: str | None = None,
           skill_on: bool = True, audio: bytes | None = None) -> dict:
    system = load_skill(role, skill_on)
    user_content = build_user_content(ctx, text or "（见语音）")
    raw = llm.complete(system, user_text=user_content, audio=audio)
    return parse(role, skill_on, raw)
```

- [ ] **Step 1: 写 `backend/app/skills/helper_skill.md`（女佣 skill v1）**

```markdown
# 女佣端照护判断 skill

你是新加坡家庭照护群聊里的判断助手。女佣（母语 Tagalog，常英菲混说）会用语音或
文字报告她对老人的观察。你的职责不是翻译，而是**判断**：这件事重不重要、该让谁知道、
该怎么对不同的人说。

## 输入
- 家庭上下文（老人慢病、用药表、last_med_change_date、复诊节奏、近期观察 recent_observations）
- 本轮女佣的观察（可能是口语、混语、含糊）

## 步骤
1. **跨语言语义还原**：把 "eat small small / no mood" 这类口语还原成临床可用表述
   （如"进食量减少约 50%"）。不要逐字翻译，要还原语义。
2. **分级**（依据上下文，不是关键词）：
   - `record`（记录，不通知）：孤立、单次、无上下文关联的日常波动。**绝大多数观察落这里。**
   - `routine`（常规通报，通知子女）：持续性改变（如 recent_observations 里同类已 ≥2 次），
     需家属知情但不紧急。
   - `escalate`（即时升级）：出现下列任一——
     a) 症状与近期用药调整（last_med_change_date）有时间关联，提示可能药物反应；
     b) 多个症状同现（如食欲下降 + 头晕/嗜睡），组合优先级高于单一症状；
     c) 明确的安全信号（站不稳、意识模糊等）。
3. **相关方判定**：
   - 与用药/临床相关的升级 → `notify` 含 `doctor`；
   - 家属需知情/需回家跟进 → 含 `child`；
   - `record` → `notify` 为空。
4. **差异化输出**：
   - `child`：口语、有解释、有今晚可做的具体动作、不制造恐慌；
   - `doctor`：结构化、带时间线、去情绪、结尾加"照护者观察，未经临床评估"；
   - `helper`：一句确认她做得对 + 一条明确的下一步观察项（减负，不追问）。

## 判断纪律
- 首要失败模式是**误报导致弃用**，不是漏报。拿不准时降一级，别升级。
- 急性事件（跌倒、意识丧失）不归你处理，属紧急按钮/995；不要假装覆盖。
```

```python
from pathlib import Path
from app import orchestrator as orch

BASE_CTX = {
    "elder": {"name": "[Ah Ma]", "age": 82, "conditions": ["[高血压]", "[2型糖尿病]"]},
    "medications": [{"name": "[Amlodipine]", "timing": "早饭后"}],
    "followups": {"clinic": "[Polyclinic]", "last_med_change_date": None},
    "household": {"primary_caregiver": "女儿[丽珍]"},
    "helper": {"mother_tongue": "Tagalog"},
    "recent_observations": [],
}

def _ctx(overrides: dict) -> dict:
    ctx = copy.deepcopy(BASE_CTX)
    for k, v in (overrides or {}).items():
        if isinstance(v, dict):
            ctx[k] = {**ctx.get(k, {}), **v}
        else:
            ctx[k] = v
    return ctx

def run(cases_path: str, llm, role: str = "helper") -> dict:
    cases = yaml.safe_load(Path(cases_path).read_text(encoding="utf-8"))
    rows, passed = [], 0
    for c in cases:
        out = orch.handle(llm, _ctx(c.get("context_overrides", {})), role,
                          c["input"], skill_on=True)
        got_grade = out.get("grade")
        got_notify = sorted(out.get("notify", []))
        exp_notify = sorted(c["expected_notify"])
        ok = got_grade == c["expected_grade"] and got_notify == exp_notify
        passed += ok
        rows.append({"name": c["name"], "expected_grade": c["expected_grade"],
                     "got_grade": got_grade, "expected_notify": exp_notify,
                     "got_notify": got_notify, "pass": ok})
    return {"total": len(cases), "passed": passed, "rows": rows}
```

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from app.repository import FamilyRepo
from app.llm import LLMClient
from app.router import route
from app import orchestrator as orch

class MessageIn(BaseModel):
    family_id: int
    sender: str
    text: str | None = None
    skill_on: bool = True

class CompareIn(BaseModel):
    family_id: int
    sender: str
    text: str | None = None

def create_app(repo: FamilyRepo, llm: LLMClient) -> FastAPI:
    app = FastAPI(title="照护协同 demo")
    app.state.repo = repo
    app.state.llm = llm

    @app.post("/families")
    def create_family(ctx: dict):
        return {"family_id": repo.create_family(ctx)}

    @app.get("/families/{fid}")
    def get_family(fid: int):
        try:
            return repo.get_family(fid)
        except KeyError:
            raise HTTPException(404, "family not found")

    def _handle(family_id, sender, text, skill_on):
        role = route(sender)
        ctx = repo.get_family(family_id)
        out = orch.handle(llm, ctx, role, text, skill_on=skill_on)
        if role == "helper" and skill_on and out.get("grade"):
            repo.add_observation(family_id, "now", text or "",
                                 out.get("restored_text", ""), out["grade"])
        return out

    @app.post("/message")
    def message(m: MessageIn):
        return _handle(m.family_id, m.sender, m.text, m.skill_on)

    @app.post("/compare")
    def compare(m: CompareIn):
        return {
            "with_skill": _handle(m.family_id, m.sender, m.text, skill_on=True),
            "without_skill": _handle(m.family_id, m.sender, m.text, skill_on=False),
        }

    return app
```

```python
import os
import httpx

class RealLLMClient(LLMClient):
    def __init__(self):
        self.base = os.environ["LLM_BASE_URL"].rstrip("/")
        self.key = os.environ["LLM_API_KEY"]
        self.model = os.environ["LLM_MODEL"]
        self.tts_model = os.environ.get("TTS_MODEL", self.model)

    def complete(self, system: str, user_text: str | None = None,
                 audio: bytes | None = None) -> str:
        content: list | str
        if audio is not None:
            # 音频输入：附带 base64 音频块。具体字段名/格式以选定模型文档为准，
            # 这里用 OpenAI 兼容的 input_audio 形态；换模型时只调此块。
            import base64
            content = [
                {"type": "text", "text": user_text or ""},
                {"type": "input_audio",
                 "input_audio": {"data": base64.b64encode(audio).decode(), "format": "wav"}},
            ]
        else:
            content = user_text or ""
        resp = httpx.post(
            f"{self.base}/chat/completions",
            headers={"Authorization": f"Bearer {self.key}"},
            json={"model": self.model,
                  "messages": [{"role": "system", "content": system},
                               {"role": "user", "content": content}],
                  "temperature": 0.2},
            timeout=60,
        )
        resp.raise_for_status()
        return resp.json()["choices"][0]["message"]["content"]

    def speak(self, text: str) -> bytes:
        resp = httpx.post(
            f"{self.base}/audio/speech",
            headers={"Authorization": f"Bearer {self.key}"},
            json={"model": self.tts_model, "input": text, "voice": "alloy"},
            timeout=60,
        )
        resp.raise_for_status()
        return resp.content
```

```markdown
# 前端契约：照护协同三人群聊 demo

## 页面
单页，WhatsApp 式三人群聊。参与者：雇主(中文)、Rosa(Tagalog)、Bot。老人不在群里。

## 顶部控件
- 开关「载入 skill ⇄ 关闭 skill」：控制发消息走 /message?skill_on 还是走 /compare 并排展示。
- 角色切换（demo 用）：当前以谁的身份发言（employer / helper）。

## 组件
1. ChatView：消息流。
2. MessageBubble：区分 employer/helper/bot 三种气泡；helper 气泡显示原文 + Bot 还原文。
3. JudgmentTag：故事A结果上方的分级标签徽章——record(灰)/routine(黄)/escalate(红)，
   旁边一行 reason（"为什么"）。
4. DifferentiatedOutputs：故事A把 outputs.child / outputs.doctor / outputs.helper
   三张卡片并排展示。
5. TaskChecklist：故事B把 confirmation_items 渲染成可勾选清单；勾选即"逐项确认"。
6. CompareView：对比模式下，同一输入的 with_skill 与 without_skill 上下并排；
   without_skill 只显示一段翻译文本，with_skill 显示完整判断卡片。
7. VoiceInput：按住说话，录音后 POST /message/audio。
8. ElderVoiceView：独立小窗，点"播放本周摘要"调 /speak 播放音频；升级时自动播放
   "这件事我需要告诉你女儿"。

## 交互流
- 发文字：POST /message，按返回渲染 JudgmentTag+DifferentiatedOutputs(helper) 或 TaskChecklist(employer)。
- 对比：POST /compare，渲染 CompareView。
- 语音：录音→/message/audio→同上渲染。
```
